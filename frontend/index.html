Built to stay fast as records grow

Three data structures from the Data Structures and Algorithms course do the heavy lifting.

Quick record lookup

An AVL tree keeps donors and units sorted and balanced, so any record is found in a handful of steps instead of scanning the whole list.

Used for: donor and unit search

Oldest-first issuing

A min-heap orders every blood type and component by expiry date, so wastage drops and near-expiry stock is flagged early.

Used for: issuing and expiry report

Nearest bank and route

Blood banks, donation camps and hospitals form a graph. Dijkstra's algorithm finds the shortest delivery route.

Used for: requests and the network map
